Hanzo Deploy Templates

The one-click deploy catalog for the Hanzo PaaS (platform.hanzo.ai). Every entry is a ready-to-run docker-compose stack with a Hanzo deploy descriptor.

Catalog API

  • /meta.json — the full catalog as a JSON array.
  • /blueprints/<id>/template.toml — a template's variables, domains and env.
  • /blueprints/<id>/docker-compose.yml — the compose stack.
  • /blueprints/<id>/<logo> — the app logo.

Deploy any of these from the Templates tab in the Hanzo PaaS. Sourced from the open-source Dokploy, Coolify, CapRover, CasaOS and Runtipi catalogs; each app keeps its upstream license and attribution — see the repository.
